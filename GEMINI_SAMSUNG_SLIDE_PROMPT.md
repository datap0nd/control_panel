# Samsung slide design extraction for Scribble

Analyze the attached PDF containing 20 representative Samsung slides to document
the Samsung presentation design standard for Scribble, our PowerPoint assistant.

Your output will be used by an engineer who cannot see the original slides.
Produce a Markdown file named `SAMSUNG_SLIDE_DESIGN_SPEC.md`.

Inspect **every slide visually**. For each slide, document:

- Its purpose, information density, and reading order.
- Placement and proportions of titles, tables, charts, commentary, and footnotes.
- Typography, colors, spacing, alignment, borders, and highlighting.
- Table and chart conventions, including units, labels, and annotations.

Then consolidate the findings into:

1. Shared design rules.
2. Reusable layout recipes with positions and sizes expressed as percentages
   of slide width and height.
3. Detailed table, chart, and annotation styling.
4. Writing conventions and how conclusions connect to supporting evidence.
5. Rules for handling content that does not fit.
6. A checklist for reviewing generated slides.
7. Uncertainties that need manual checking in PowerPoint.

Cite the relevant slide numbers for every rule. Distinguish measured values
from visual estimates. Do not invent exact font names, sizes, or colors.

Preserve the actual density and structure of these slides. Avoid generic
presentation advice.

Use neutral placeholders instead of actual business figures, project names,
or confidential narrative. We need the reusable design standard.

If you cannot visually inspect a slide, identify it explicitly.

Return the complete result as a downloadable Markdown file. If downloads
are unavailable, print the Markdown so I can copy it into a file.
